# Ресурс pnpm

Текущая версия и ресурсы для всех платформ хранятся в [catalog.json](catalog.json).
Из каталога генерируются [package.json](package.json), [pnpm.sbr.json](pnpm.sbr.json)
и [инклюд тулчейна](../../../devtools/frontend_build_platform/docs/src/_generated/toolchain-includes/020-pnpm.md).

Скрипт обновления и проверки находятся в [pnpm-patches](../../../devtools/frontend_build_platform/pnpm-patches/README.md).
