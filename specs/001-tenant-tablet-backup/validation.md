в `ydb/core/mind/hive/ut`, session ID `25296`. Результат пока неизвестен.
Следующая проверка состояния — не раньше 17:48 МСК (14:48 UTC).

В процессе статической проверки обнаружено, что helper `RebootTablet` ждёт `TEvBoot`,
который recovery выдаёт только при применении бекапа. Для перезапуска recovery-экземпляра
тест должен ждать новый recovery boot через Local, а не вызывать этот helper. Исправление
будет внесено после текущей сборки, чтобы не менять её входные файлы во время компиляции.

Дополнительные замечания статической проверки для следующей итерации:

- Добавить ResourceBroker для backup scan в setup нового Hive-теста.
- Перед boot проверять именно SupportsRecovery; полная IsAbleToRunTablet включает
  изменяемые лимиты ресурсов и не должна оставлять таблетку в Starting при отказе.
- Дополнить проверки старого Local без capability и запрета запуска followers в recovery.
- Операторская инструкция в русской и английской версии подготовлена; сценарий ещё не проверен.
