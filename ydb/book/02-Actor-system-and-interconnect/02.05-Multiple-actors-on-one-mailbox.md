## 2.5 Несколько акторов на одном мейлбоксе

С одним мейлбоксом может быть связан один или несколько акторов.
Зарегистрировать второго актора на свой мейлбокс можно, только находясь
внутри обработки сообщения актором. Сообщения, пришедшие на один
мейлбокс, обрабатываются однопоточно. Таким образом, если с мейлбоксом
связано несколько акторов, обрабатывать сообщения они будут однопоточно
из единой очереди в FIFO-порядке. Как следствие, становятся возможными
прямые вызовы между акторами при сохранении раздельных уникальных
адресов для получения сообщений.
