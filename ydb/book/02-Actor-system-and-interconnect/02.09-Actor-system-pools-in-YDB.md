## 2.9 Пулы акторной системы YDB

В акторной системе YDB есть несколько пулов.

System Pool. Предназначен для быстрой обработки коротких сообщений
(менее 1 мс). В этом пуле выполняются акторы распределённого хранилища.

User Pool. Предназначен для обработки пользовательской нагрузки. В нём
работают таблетки, например, Data Shard. Некоторые сообщения могут
обрабатываться относительно долго (порядка 5 мс).

Batch Pool. Предназначен для обработки фоновой нагрузки. В нём
запускаются акторы, для которых приемлема активация через существенный
промежуток времени (иногда около 100 мс).

IC Pool. Специальный пул для интерконнекта (подсистемы, обеспечивающей
передачу сообщений между нодами).

IO Pool. Предназначен для блокирующих операций ввода-вывода. В этом пуле
работает актор логирования.

Количество тредов в тред-пуле устанавливается при старте системы и не
изменяется в процессе работы. При этом количество используемых потоков в
конкретный момент времени может изменяться и быть меньше максимального.
Специальный объект Harmonizer следит за загрузкой потоков в разных пулах
и изменяет количество используемых потоков пула: он увеличивает
количество используемых потоков в перегруженных пулах и уменьшает в
недогруженных. При этом он следит за тем, чтобы потоков не становилось
слишком много и они не вытесняли друг друга с процессорных ядер.

В системном пуле работает io dispatcher actor, в который можно отправить
запрос, который этот актор отправит выполняться в специальный тред-пул
для IO. Это динамический тред-пул, предназначенный для выполнения
различных задач, связанных с синхронным вводом-выводом. Фактически на
вход передаётся сообщение, содержащее callback, а он присылает
результат. IO dispatcher actor создаётся в акторной системе по
умолчанию.
