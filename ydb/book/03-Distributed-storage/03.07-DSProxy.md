## 3.7 DSProxy

DSProxy --- это компонент, который предоставляет интерфейс для записи,
чтения и удаления блобов в Distributed Storage. Ниже показаны основные
параметры запросов; необязательные завершающие параметры конструкторов,
не участвующие в объяснении, опущены.

**TEvPut**

Записать блоб с идентификатором id и значением buffer. Прервать операцию
если наступает момент времени deadline. Обрабатывать запрос на VDisk-е
по классу handleClass.

```cpp
TEvPut(const TLogoBlobID &id, const TString &buffer, TInstant deadline,
       NKikimrBlobStorage::EPutHandleClass handleClass =
           NKikimrBlobStorage::TabletLog)
```

**TEvGet**

Прочитать size байт данных блоба с идентификатором id начиная с байта
shift. Если size равен 0, данные читаются до конца. Прервать операцию,
если наступает момент времени deadline. Если выставлен флаг
mustRestoreFirst, восстановить полное количество копий частей блоба на
различных VDisk-ах группы, прежде чем возвращать данные. Параметр
getHandleClass задаёт класс обслуживания чтения, например FastRead
или AsyncRead. Если
выставлен флаг isIndexOnly, не возвращать данные блоба, а лишь убедиться
в его наличии в индексе VDisk-ов.

```cpp
TEvGet(const TLogoBlobID &id, ui32 shift, ui32 size, TInstant deadline,
       NKikimrBlobStorage::EGetHandleClass getHandleClass,
       bool mustRestoreFirst = false, bool isIndexOnly = false)
```

Вторая форма этого запроса --- для чтения нескольких фрагментов данных
блобов, идентификаторы, смещения и размеры считываемых данных передаются
в массиве записей TQuery q.

```cpp
struct TQuery {
    TLogoBlobID Id;
    ui32 Shift;
    ui32 Size;
};

TEvGet(TArrayHolder<TQuery> &q, ui32 sz, TInstant deadline,
       NKikimrBlobStorage::EGetHandleClass getHandleClass,
       bool mustRestoreFirst = false, bool isIndexOnly = false)
```

**TEvDiscover**

Найти в нулевом канале таблетки tabletId успешно записанный блоб с
максимальным идентификатором и вернуть этот идентификатор. Поиск
ограничен поколениями не ниже minGeneration. Если
выставлен флаг readBody, то для этого блоба будет возвращено его
содержимое. Если выставлен флаг discoverBlockedGeneration, будет найден
номер заблокированного поколения. Прервать операцию, если наступает
момент времени deadline. Эта операция критически важна при запуске
таблетки для определения последнего успешно записанного блоба и
продолжения работы с корректного состояния.

```cpp
TEvDiscover(ui64 tabletId, ui32 minGeneration, bool readBody,
            bool discoverBlockedGeneration, TInstant deadline,
            ui32 forceBlockedGeneration, bool fromLeader)
```

**TEvCollectGarbage**

Передвинуть барьер/пометить блобы как не мусор/мусор в канале channel
таблетки tabletId. Эта операция позволяет таблеткам управлять жизненным
циклом своих блобов, удаляя ставшие ненужными части лога и сохраняя
важные снимки состояния (модель сборки мусора описана в разделе 3.1). Прервать операцию, если наступает момент времени
deadline. Операция по сути является операцией записи метаданных с
поколением recordGeneration. Если выставлен флаг collect, то барьер
сборки мусора смещается на поколение collectGeneration и шаг
collectStep. Векторы keep и doNotKeep содержат идентификаторы блобов,
для которых нужно выставить соответствующие флаги. Показанный
конструктор принимает владение переданными векторами: их нельзя
передавать как указатели на объекты на стеке или освобождать после
передачи. Нулевой указатель означает отсутствие соответствующего
списка. Каждая операция
должна иметь уникальный номер perGenerationCounter в рамках каждого
поколения recordGeneration. Если выставлен флаг isMultiCollectAllowed,
операции с большим количеством флагов keep/doNotKeep будут разделены на
несколько операций с последовательно возрастающими номерами
perGenerationCounter. При этом предполагается, что таблетка в следующем
запросе будет использовать perGenerationCounter, увеличенный на
значение, полученное из вызова 

```cpp
TEvCollectGarbage::PerGenerationCounterStepSize(
    TVector<TLogoBlobID> *keep, TVector<TLogoBlobID> *doNotKeep)

TEvCollectGarbage(ui64 tabletId, ui32 recordGeneration,
                  ui32 perGenerationCounter, ui32 channel,
                  bool collect, ui32 collectGeneration,
                  ui32 collectStep, TVector<TLogoBlobID> *keep,
                  TVector<TLogoBlobID> *doNotKeep,
                  TInstant deadline, bool isMultiCollectAllowed)
```
**TEvBlock**

Заблокировать запись в таблетку tabletId с поколением меньше или равным
generation. Прервать операцию, если наступает момент времени deadline.
Эта операция обеспечивает единственность активного экземпляра таблетки.

```cpp
TEvBlock(ui64 tabletId, ui32 generation, TInstant deadline)
```

**TEvStatus**

Получить флаги статуса дисков группы. Прервать операцию, если наступает
момент времени deadline. Флаги позволяют таблеткам адаптировать своё
поведение в зависимости от состояния хранилища (например,
перераспределять нагрузку между несколькими группами хранения в
зависимости от степени заполненности этих групп).

```cpp
TEvStatus(TInstant deadline)
```
