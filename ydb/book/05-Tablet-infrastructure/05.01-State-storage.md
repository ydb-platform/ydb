## 5.1 Хранилище состояний

State Storage --- это распределённое волатильное хранилище в памяти данных,
в общих чертах о нём можно думать как о DHT. Предназначен для быстрого
обнаружения текущего инстанса таблетки в кластере.

Состоит из набора акторов реплик state storage, запущенных на разных
нодах. Одна или несколько реплик state storage объединяются в кольцо,
кольца используются для распределения нагрузки между репликами в кольце,
данные конкретной таблетки могут храниться только на одной из реплик
кольца, выбираемой по хешу от идентификатора таблетки. Для
обеспечения отказоустойчивости данные дублируются на реплики в разных
кольцах, при этом для хранения данных конкретной таблетки выбирается N
колец и данные считаются успешно записанными в state storage если на
большинство из N колец запись выполнена успешно.

В стейт-сторадже лежат данные про таблетки. Таблетка на старте в
стейт-сторадж публикует информацию про себя --- свои координаты. Она
сможет это сделать если её поколение больше, чем уже имеющееся в
стейт-сторадже поколение. Если совпадает --- она получит ошибку.

State Storage Tablet Guardian --- следит за соединением с нодами
стейт-стораджа и при получении уведомления о разрыве сетевого соединения пытается заново записать данные на
соответствующую ноду стейт-стораджа исходя из предположения что та нода
перезапустилась и потеряла данные.
