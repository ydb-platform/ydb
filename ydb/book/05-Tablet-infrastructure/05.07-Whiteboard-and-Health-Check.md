## 5.7 Доска состояния и проверка работоспособности

Whiteboard --- локальный сервис на каждой ноде, агрегирующий информацию
о состоянии компонентов. Для получения состояния кластера выполняется
обход всех нод, данные с их Whiteboard-ов собираются и агрегируются.

В Whiteboard публикуют информацию многие акторы: каждый VDisk
сообщает своё состояние, аналогично поступают таблетки. Этими данными
пользуются Health Check и другие компоненты, обращающиеся
к Whiteboard-ам всех нод для сбора информации.

Health Check --- сервис, сообщающий о состоянии базы данных. При
обнаружении проблем он выдаёт список ошибок: переполнение диска,
исчерпание пула на ноде и т. п. Информацию он собирает из множества
источников, опрашивая Scheme Shard, Hive, ноды и BS_Controller.

Health Check выполняет сбор и анализ информации по запросу,
создавая для проверки отдельный актор. Сам сервис не запускает
периодические проверки состояния кластера.

Отдельный слой --- кэш метаданных базы данных. При включённом
EnableDbMetadataCache активный экземпляр кэша, выбранный с помощью
Board, периодически запрашивает Health Check и сохраняет последний
результат в памяти. Такое обновление происходит и без пользовательских
запросов. HTTP-интерфейс проверки может использовать этот результат,
если указана база данных, разрешено использование кэша и включено
объединение записей merge_records. По умолчанию флаг
EnableDbMetadataCache выключен.

Изначально Health Check был рассчитан на проверку конкретной базы.
Однако потребовалась возможность проверять все базы кластера, для чего
сервис сначала собирает список баз, а затем проверяет каждую из них.
Вызов Health Check без указания базы фактически означает проверку
всего кластера: нода, обрабатывающая запрос, соединяется со всеми
нодами всех баз. При прямых проверках повторные запросы одного
клиента целесообразно направлять на одну и ту же ноду, чтобы не
расширять набор межнодовых соединений без необходимости.
При этом каждый прямой запрос по-прежнему запускает отдельную проверку;
повторное использование её результата обеспечивает описанный выше кэш.
