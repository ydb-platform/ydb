# 6 Основные виды таблеток

Конкретная функциональность YDB
реализована через специализированные типы таблеток. Каждый тип таблетки
решает свой класс задач, используя распределённое хранилище и общую
инфраструктуру таблеток.

Таблетка DataShard является основным строительным блоком для хранения
пользовательских данных в строковых таблицах. Каждый DataShard отвечает
за диапазон ключей в таблице, выполняет SQL-запросы к своим данным и
участвует в распределённых транзакциях.

Таблетка ColumnShard реализует колоночное
хранилище для эффективной аналитической обработки больших объёмов данных.

KeyValue-таблетка предоставляет простой интерфейс ключ-значение для
записи и чтения блобов в распределённом хранилище.

Таблетка PersQueue реализует партиции топиков, обеспечивая
гарантированную доставку сообщений и поддержку множества читателей.

Таблетка Kesus предоставляет примитивы распределённой координации:
сессии, персистентные и эфемерные семафоры.

Таблетки Coordinator и Mediator координируют распределённые
транзакции между множеством DataShard, PersQueue, ColumnShard.
