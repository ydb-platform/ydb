# 8 Слой выполнения запросов

Слой выполнения запросов является точкой входа для пользователей в YDB,
предоставляя SQL-интерфейс для работы с данными. Он решает задачу
преобразования SQL-запросов в эффективный план выполнения,
который координирует работу множества DataShard и ColumnShard,
обеспечивая гарантии транзакционности и оптимальную
производительность.

Когда пользователь отправляет SQL-запрос, система должна разобрать его,
проверить корректность, оптимизировать, составить план выполнения,
распределить работу между участниками, собрать результаты.
При этом необходимо минимизировать
передачу данных по сети и обеспечивать справедливое распределение
ресурсов между конкурирующими запросами.

YQL является диалектом SQL, расширяющим стандартный синтаксис
возможностями для работы с полуструктурированными данными, функциями для
обработки сложных типов и конструкциями для управления выполнением
распределённых вычислений.

Глава описывает основные компоненты слоя выполнения: KQP как
движок выполнения запросов, компиляцию и оптимизацию запросов, путь
прохождения запроса от клиента до DataShard, систему просмотра системных
таблиц через SysViewProcessor, а также использование типов и функций
PostgreSQL в YQL и хранение PG-значений в строковых таблицах.
