## 9.3 Control plane

Control plane управляет жизненным циклом баз: создаёт и удаляет их, меняет настройки, организует выделение вычислительных ресурсов и выполнение резервного копирования. Для этих операций ему выдаются необходимые административные права. Какие из них доступны обычному пользователю напрямую, определяется политикой конкретного сервиса.

Между созданием базы в YDB и запуском обслуживающих её процессов есть отдельная граница. Через управляющие API можно создать базу и настроить её ресурсы, но процессы динамических нод должны быть запущены на физической или виртуальной инфраструктуре. Их последующая регистрация в кластере описана в разделе 12.2.

Реализация внешнего control plane зависит от среды развёртывания. В описываемой внутренней инсталляции это отдельный сервис на Python, построенный не из акторов и таблеток. Он обращается к YDB по gRPC, создаёт тенанты и задаёт конфигурацию баз. Собственное состояние --- сведения о базах, резервных копиях и расписаниях --- сервис хранит в отдельной базе YDB.

При управлении физическими машинами такой control plane ведёт список доступных хостов и слотов для запуска процессов. Базе назначается требуемое количество слотов с учётом их типа и размещения по дата-центрам. Например, для размещения в трёх ДЦ нужное количество слотов выделяется в каждом из них. В запущенный процесс передаётся путь обслуживаемого тенанта. Эти вычислительные слоты не следует путать со слотами VDisk на PDisk.

В облачной среде аналогичную роль выполняет выделение виртуальных машин. Control plane может обращаться к сервису управления группами ВМ, задавая требуемое число экземпляров. Образ машины содержит программное обеспечение, а параметры конкретной базы передаются через конфигурацию запуска или метаданные группы. При старте процесс получает путь тенанта и параметры подключения к кластеру.

Язык реализации control plane, число его экземпляров, место их запуска и способ хранения служебного состояния выбираются при проектировании инсталляции. Например, внешний сервис может размещаться рядом с кластером, в котором хранит свои метаданные.
