## 10.2 ydb cli

В этом разделе рассмотрены назначение, структура команд и основные сценарии использования утилиты `ydb`.

Утилита `ydb` — это универсальный клиент командной строки для работы с YDB. Она используется для выполнения SQL-запросов, управления схемой данных и запуска нагрузочных тестов, а также для мониторинга и базового управления кластером. Утилита является кроссплатформенной (написана на C++) и взаимодействует с кластером через публичный gRPC API (используя YDB C++ SDK).

### Основные группы команд

Команды утилиты сгруппированы в иерархическое дерево. Утилита позволяет выполнять:

- администрирование кластера;
- управление схемой базы;
- работу с данными;
- нагрузочное тестирование.

### Настройка подключения и профили

Для выполнения любой команды необходимо указать, к какому кластеру и базе данных нужно подключиться, а также параметры аутентификации (токен, файл сервисного аккаунта, логин/пароль).

YDB CLI поддерживает профили, которые сохраняют параметры подключения
под короткими именами. Это позволяет не указывать параметры при каждом
вызове команды.

### Форматы вывода

Большинство команд поддерживают выбор формата представления результата:

* Таблицы с псевдографикой, удобные для чтения человеком;
* csv — табличный текстовый формат, с которым легко работать из shell-скриптов;
* JSON, хорошо подходящий для парсинга из скриптов.
