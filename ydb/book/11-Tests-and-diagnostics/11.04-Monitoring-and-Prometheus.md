## 11.4 Мониторинг и Prometheus

Monlib --- библиотека, которая позволяет иерархически организовывать
счётчики в виде дерева. Счётчики регистрируются в общем хранилище,
из которого мониторинг периодически забирает данные через Spack или
через JSON. Для работы с иерархией счётчиков
используется RWLock: при поиске счётчика берётся read-lock, при
добавлении --- write-lock. Блокировки берутся по мере прохождения
по дереву.

Состояние всего дерева счётчиков в памяти выдаётся по http-интерфейсу в
одном из поддерживаемых форматов --- Prometheus, JSON и Spack.

Для получения данных в формате Prometheus служит специальный API интерфейс
counters/something/prometheus. В Monlib есть код, который формирует
выдачу в формате, совместимом с Prometheus. Сейчас это только текст, нет
binary-представления, причем полное имя каждого сенсора указывается
полностью. Если у гистограммы 20 диапазонов, это означает, что для каждого
диапазона дублируется полное имя гистограммы плюс имя диапазона. Это позволяет
как угодно перемешивать строки, но очень заметно раздувает объём.

Сам мониторинг пользуется сейчас Spack. Это компактный формат.
