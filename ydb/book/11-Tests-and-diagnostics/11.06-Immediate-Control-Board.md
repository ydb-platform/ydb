## 11.6 Оперативная подстройка параметров

Immediate Control Board --- это инструмент, позволяющий выполнять тонкую
подстройку параметров прямо во время работы системы через веб-интерфейс.
Параметры выставляются путем регистрации объекта специального класса,
содержащего атомарную переменную. При просмотре на веб-странице
immediate control board отображается список выставленных параметров, их
текущие и первоначальные значения. Можно поменять значение параметра и
нажать кнопку «Применить», после чего значение атомарной переменной в
соответствующем объекте будет изменено. Это позволяет выполнять тонкую
регулировку системы быстро и просто, без перезапуска компонентов, прямо
посреди работы системы и сразу же наблюдать реакцию системы на изменение
параметров. Измененные значения подсвечиваются в веб-интерфейсе, но не
сохраняются нигде, кроме памяти, а после перезапуска процесса изменения
будут потеряны. Это инструмент не для управления продакшн-кластером, а
для проведения экспериментов.


Для расширения функциональных возможностей Immediate Control Board
в YDB есть сопряжение ICB и настроек из конфигурации, получаемой узлами
в процессе работы от Console. Работает это следующим образом:


- администратор вносит изменения в файл конфигурации и применяет её;
- конфигурация применяется таблеткой Console, которая рассылает её в сервисы конфигурации на всех узлах кластера;
- конфигурация передаётся подписанным на изменения конфигурации акторам, в том числе актору ImmediateControlsConfigurator;
- ImmediateControlsConfigurator проходит по всем параметрам конфигурации в разделе immediate_controls_config;
- Для каждого указанного в конфигурации параметра его значение применяется как новое значение одноименного параметра в ICB.

В результате становится возможно практически мгновенное изменение значений
атомарных переменных ICB на множестве узлов кластера путем применения
файла конфигурации ydb.

При необходимости можно управлять тем, на каких узлах будет изменено
значение настроек при помощи механизма селекторов конфигурации.
