## 11.9 Генераторы нагрузки Load Actor

Подавать нагрузку на различные подсистемы YDB можно при помощи
специальных акторов-нагружателей. Нужно сформировать конфигурацию и
передать её актору, после чего он будет генерировать нагрузку в
соответствии с переданными настройками. По завершении работы
акторы-нагружатели формируют отчеты. Подробнее --- в документации:

<https://ydb.tech/ru/docs/development/load-actors-overview>

Акторы-нагружатели могут подавать нагрузку на всех уровнях
системы: для PDisk, для VDisk, для Interconnect (IC Load). Последний запускает акторы, которые шлют сообщения аналогичным
акторам на других нодах. Причем для сообщений можно указать маршрут по
нодам, который оно должно пройти. На произвольном этапе можно сбросить
пейлоад, эмулируя тяжелый запрос с легким ответом. Это позволяет
измерять пропускную способность и времена отклика.

Отдельные нагружатели есть для DSProxy, памяти на машине и KV-таблетки.

Для имитации медленного актора есть slowpoke actor. Он запускается
в указанном пуле и периодически получает сообщение, в ответ на которое
делает sleep. Интервалы между такими сообщениями и длительность sleep
задаются настройками. Занимая рабочий поток, он может задерживать
выполнение других акторов этого пула.

А ещё в интерконнекте есть отладочные интерфейсы, позволяющие прибивать
сессии, рвать TCP-соединения и т. п. Эти интерфейсы доступны и на production-кластерах, что следует учитывать при эксплуатации.
