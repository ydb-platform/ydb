## 11.12 Тесты на Python

Помимо C++-тестов (раздел 11.7) в YDB существует обширный набор
интеграционных тестов на Python. Они позволяют поднять полноценный
кластер YDB из нескольких нод в рамках одного тестового процесса
и проверить поведение системы на уровне gRPC API --- так, как это
делает реальное клиентское приложение.

### Тестовый фреймворк

Основой является библиотека `ydb/tests/library/harness`, которая
предоставляет классы для управления локальным кластером. Класс
`KiKiMR` поднимает кластер из нескольких процессов `ydbd` на
локальной машине, автоматически выделяя порты для gRPC, interconnect
и мониторинга. Класс `ExternalKiKiMRCluster` позволяет управлять
уже развёрнутым кластером на удалённых машинах через SSH.

Фреймворк поддерживает конфигурации с произвольным числом нод,
включая статические и динамические ноды с несколькими тенантами.
Тесты могут останавливать и перезапускать отдельные ноды, что
позволяет проверять поведение системы при отказах.

### Категории тестов

Функциональные тесты (`ydb/tests/functional/`) покрывают основные
подсистемы: blobstorage, hive, cms, kqp, scheme_shard, serverless,
encryption, replication, ttl, PostgreSQL-совместимость и другие.
Каждая подсистема имеет отдельный каталог с тестами.

Канонизационные тесты проверяют стабильность планов выполнения
запросов: результат компиляции YQL-запроса сравнивается с эталонным
(канонизированным) значением. При изменении плана тест падает, что
позволяет обнаружить непреднамеренные регрессии оптимизатора.

Тесты сериализуемости (`ydb/tests/functional/serializable/`,
`ydb/tests/library/serializability/`) проверяют, что результаты
параллельного выполнения транзакций соответствуют гарантиям
serializable-изоляции.

Тесты serverless-квот проверяют, что при превышении квоты request
unit операции записи корректно отклоняются с соответствующей ошибкой.

### Запуск тестов

Тесты запускаются системой сборки `ya make` (или `ya test`). Часть
тестов выполняется при каждом коммите (покоммитные), часть --- только
в рамках периодических прогонов, поскольку полный набор тестов
требует значительного времени.
