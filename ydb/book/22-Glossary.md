# Глоссарий

В этом разделе собраны краткие определения основных терминов, используемых в книге.

*   **Актор (Actor)** — Основной примитив параллелизма в YDB. Легковесный объект C++, имеющий состояние и обменивающийся сообщениями с другими акторами.
*   **Акторная система (Actor System)** — Среда выполнения акторов, управляющая пулами потоков, доставкой сообщений и планированием.
*   **ActorId** — Уникальный адрес актора в кластере, состоящий из идентификатора ноды, пула и локального номера.
*   **Блоб (Blob)** — Неизменяемая последовательность байт произвольного размера (до ~10 МБ), снабженная коротким двоичным идентификатором LogoBlobID и хранимая в BlobStorage.
*   **BlobStorage (BS)** — Нижний слой YDB, обеспечивающий надёжное распределённое хранение данных на дисках.
*   **Board** — Распределённый сервис (хранилище пар ключ-значение в памяти), используемый для публикации и поиска информации о составе нод кластера (discovery).
*   **Bootstrapper** — Специальный актор, отвечающий за запуск и перезапуск системных таблеток на нодах.
*   **BS_Controller** — Системная таблетка, управляющая конфигурацией BlobStorage, группами хранения, PDisk-ами и VDisk-ами.
*   **CMS (Cluster Management System)** — Системная таблетка, проверяющая допустимость плановых операций обслуживания кластера и выдающая разрешения на них с учётом состояния компонентов.
*   **Координатор (Coordinator)** — Таблетка, отвечающая за планирование распределённых транзакций и назначение им порядка выполнения (PlanStep).
*   **Даташард (DataShard)** — Таблетка, отвечающая за хранение и обработку диапазона строк одной таблицы. Участвует в распределённых транзакциях.
*   **DSProxy** — Актор-прокси на ноде, через который таблетки пишут и читают данные из BlobStorage. Отвечает за erasure coding и шифрование блобов.
*   **Избыточное кодирование (erasure coding)** — Метод избыточного кодирования данных, позволяющий восстанавливать данные при потере части дисков без полного дублирования.
*   **Поколение (Generation)** — Монотонно возрастающий номер запуска (инкарнации) таблетки. Используется для получения гарантии того, что только один экземпляр таблетки может писать в лог.
*   **Группа хранения (Group)** — Набор VDisk-ов с заданной топологией и режимом избыточности. Для размещения конкретного блоба из него выбирается подгруппа.
*   **Hive** — Системная таблетка, управляющая размещением, запуском, балансировкой и состоянием переданных ей в управление таблеток.
*   **Интерконнект (Interconnect)** — Подсистема сетевого взаимодействия, обеспечивающая доставку сообщений между акторами на разных нодах с использованием TCP.
*   **KQP (Kikimr Query Processor)** — Компонент, отвечающий за выполнение YQL запросов: оптимизацию, построение физического плана и исполнение.
*   **Local** — Локальный сервис на каждой ноде, управляющий запуском таблеток по командам от Hive.
*   **LogoBlobID** — Уникальный идентификатор блоба, содержащий TabletID, Generation, Step и другие метаданные.
*   **Мейлбокс (Mailbox)** — Очередь сообщений, привязанная к одному или нескольким акторам. Обрабатывается одним потоком-читателем в каждый момент времени.
*   **Медиатор (Mediator)** — Таблетка-посредник, рассылающая планы транзакций от Координаторов к Даташардам.
*   **Нода (Node)** — Процесс `ydbd`, исполняемый на сервере. Кластер YDB состоит из множества нод, взаимодействующих по сети.
*   **Node Warden** — Локальный сервис ноды, управляющий компонентами BlobStorage (PDisk, VDisk, DSProxy).
*   **PDisk (Physical Disk)** — Компонент, управляющий блочным устройством. Отвечает за запись чанков и лога на диск.
*   **SchemeBoard** — Распределённый кэш метаданных схемы (таблиц, путей), реплицируемый в памяти для быстрого доступа при компиляции запросов, чтобы снизить нагрузку на SchemeShard.
*   **Схемшард (SchemeShard)** — Таблетка, хранящая схему базы данных (описания таблиц, индексов, прав доступа).
*   **Slot (VDisk Слот)** — Единица ресурсов (места) на PDisk, выделяемая для работы одного VDisk. Ограничивает количество VDisk-ов на одном PDisk для контроля нагрузки. 
*   **Slot (ControlPlane Слот)** — Единица выделения ресурсов (процесса) на хосте для запуска динамической ноды (обычно в контексте Control Plane).
*   **StateStorage** — Распределённое хранилище в памяти (DHT) для быстрого обнаружения расположения таблеток.
*   **Шаг (Step)** — Номер операции (или записи в лог) внутри одного поколения таблетки.
*   **Таблетка (Tablet)** — Реплицированный конечный автомат (RSM), работающий поверх BlobStorage. Основной строительный блок логики YDB.
*   **TabletPipe** — Механизм установления логического соединения между актором и таблеткой (или двумя таблетками) с гарантией порядка доставки сообщений и уведомлением о разрыве.
*   **Тенант/База данных (Tenant)** — Логически обособленная база данных в кластере YDB со своим пространством имён и правами доступа. Вычислительные ресурсы и часть инфраструктуры могут быть общими с другими базами.
*   **VDisk (Virtual Disk)** — Компонент, работающий поверх PDisk и реализующий логику хранения блобов, репликации и восстановления в составе группы хранения. Использует LSM-дерево.
*   **YQL (YDB Query Language)** — Диалект SQL, используемый в YDB для написания запросов.
