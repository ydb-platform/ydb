### Custom logic over kernels

Program nodes provide some optimizations that cannot be achieved via plain kernel execution, such as avoiding unwrapping dictionary and sparsed arrays (because kernels support only plain arrow arrays by default)

#### Coalesce

Short-circuits on first input if it has no nulls and the correct type.

#### And/Or

A sequence of And/Or is flattened into N-ary predicate (`TStreamLogicProcessor`) that handles its inputs as they become ready. It also recognizes mono-value representations (`CheckOneValueAccessor`) and handles them as either absorbing (Value OP Any == Value) or neutral (Value OP Any == Any).
Mono-value arrays are mostly generated by index checks, but may occur naturally, like a dictionary column with a single value.
