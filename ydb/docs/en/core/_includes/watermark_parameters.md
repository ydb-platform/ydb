* `WATERMARK` — expression for calculating the [watermark](../dev/streaming-query/watermarks.md). Currently, only the write time to a [topic](../concepts/datamodel/topic.md) with a constant delay is supported. Format: `__ydb_write_time - Interval("<delay>")`, where `<delay>` is specified in [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601#Durations) format.
* `WATERMARK_GRANULARITY` — watermark generation interval. The smaller it is, the higher the CPU consumption by the query and the lower the response latency. Only meaningful for [streaming queries](../dev/streaming-query/index.md). Specified in [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601#Durations) format. Default value is 1 second.
* `WATERMARK_IDLE_TIMEOUT` — period after which an [idle partition](../dev/streaming-query/watermarks.md#idle-partitions) will be excluded from the combined watermark calculation. Only meaningful for [streaming queries](../dev/streaming-query/index.md). Specified in [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601#Durations) format. Default value is 5 seconds.
