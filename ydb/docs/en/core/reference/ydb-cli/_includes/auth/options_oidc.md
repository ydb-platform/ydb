- `--oidc-config <filepath>`: Enables OIDC/OAuth authentication using the YAML configuration file at `<filepath>`. The file must specify an HTTPS `issuer` and exactly one flow: `static_credentials`, `client_credentials_grant`, or `device_authorization_grant`. Client Credentials uses `client_id` and `client_secret`; Device Authorization uses `client_id` and prints the verification URL and user code. Static credentials may specify `client_id` and `refresh_token` to enable refresh. The `openid` scope is always requested. Optional `cache_path` stores rotated tokens in a private, owner-only JSON file; relative paths are resolved from the OIDC configuration directory.
