# Sequence

Sequence представляет собой генератор целочисленных значений, принадлежащий колонке [строковой таблицы](table.md#row-oriented-tables) {{ ydb-short-name }}. {{ ydb-short-name }} автоматически создаёт его для каждой колонки [серийного типа](../../yql/reference/types/serial.md), как ключевой, так и неключевой, чтобы генерировать значение, когда оно не указано при записи строки.

## Владение и жизненный цикл

Созданный объект является приватным и размещается по пути `<table_path>/_serial_column_<column_name>`, где `<table_path>` задаёт путь таблицы, а `<column_name>` задаёт имя серийной колонки. Например, для колонки `user_id` таблицы `/Root/users` путь генератора будет `/Root/users/_serial_column_user_id`. Объект скрыт в списке схемных объектов, а его жизненный цикл связан с колонкой.

Параметры генератора доступны для изменения командой [ALTER SEQUENCE](../../yql/reference/syntax/alter-sequence.md) по этому пути. Отдельные команды `CREATE SEQUENCE` и `DROP SEQUENCE` в YQL не поддерживаются, поскольку объект создаётся и удаляется вместе с серийной колонкой.

Удаление неключевой колонки Serial удаляет её Sequence. Удаление таблицы также удаляет все принадлежащие ей Sequence.

## Генерируемые значения

По умолчанию генератор начинает выдавать значения с 1, увеличивает их на 1 и ограничивает диапазон в соответствии с серийным типом. Доступные типы и их границы описаны в [справочнике серийных типов](../../yql/reference/types/serial.md).

{{ ydb-short-name }} выделяет значение до записи строки в таблицу. Значение считается использованным, даже если запись завершилась ошибкой или транзакция была отменена, поэтому в последовательности допустимы пропуски. При конкурентных записях порядок выделенных значений также может отличаться от порядка создания строк.

Сброс командой `ALTER SEQUENCE RESTART` может привести к повторной выдаче использованных значений. Серийный тип сам по себе не накладывает ограничение уникальности на колонку. Подробнее о явной записи значений и конфликтах по полному первичному ключу см. в разделе [{#T}](../../yql/reference/types/serial.md#explicit-values).

## Операции с таблицами

Для таблиц с колонками Serial поддерживаются следующие операции:

- [copy](../../reference/ydb-cli/tools-copy.md)
- [rename](../../reference/ydb-cli/commands/tools/rename.md)
- [dump](../../reference/ydb-cli/export-import/tools-dump.md) и [restore](../../reference/ydb-cli/export-import/import-file.md)
- [импорт из S3](../../reference/ydb-cli/export-import/import-s3.md) и [экспорт в S3](../../reference/ydb-cli/export-import/export-s3.md)

При переименовании таблицы пути связанных с ней Sequence изменяются в соответствии с новым путём таблицы, а их параметры и текущие позиции сохраняются.

При выгрузке такой таблицы не используйте [`--avoid-copy`](../../reference/ydb-cli/export-import/tools-dump.md), поскольку без копирования актуальная позиция генератора не сохраняется в дампе.
