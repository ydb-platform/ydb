{% note warning %}

Система сборки может объединить несколько файлов `.cpp` в одну единицу компиляции с помощью `JOIN_SRCS`, который подключает их через директивы `#include`. Поэтому в конце каждого исходного файла настоятельно рекомендуется отменять определение макроса:

```cpp
#undef YDB_LOG_THIS_FILE_COMPONENT
```

В противном случае определение макроса `YDB_LOG_THIS_FILE_COMPONENT` может распространиться на несколько файлов исходного кода.

{% endnote %}
