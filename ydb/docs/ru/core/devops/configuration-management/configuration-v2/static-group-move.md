# Перемещение статической группы

{% cut "Статья находится в разработке" %}

{% include [_](../_includes/experimental_v2.md) %}

При использовании Конфигурации V2 управление статической группой выполняется автоматически: механизм SelfHeal реконфигурирует группу при отказе одного из её узлов.

Если требуется управлять конфигурацией статической группы вручную, отключите автоматическое управление, получите текущую конфигурацию, внесите изменения и примените её как целевую. Затем удалите целевую конфигурацию статической группы из файла конфигурации и снова включите автоматическое управление.

{% include [warning-configuration-error](../configuration-v1/_includes/warning-configuration-error.md) %}

В качестве примера рассмотрим кластер {{ ydb-short-name }}, в котором на хосте с `node_id:1` сконфигурирован и запущен [статический узел](../../../devops/configuration-management/configuration-v2/config-settings.md#hosts). Этот узел обслуживает часть статической группы.

Фрагмент конфигурации статической группы:

```yaml
...
groups:
  ...
  rings:
    ...
    fail_domains:
    - vdisk_locations:
      - node_id: 1
        path: /dev/vda
        pdisk_category: SSD
    ...
...
```

Для замены `node_id:1` используйте другой хост с развернутым на нем статическим узлом с `node_id:10`.

Чтобы переместить часть статической группы с хоста `node_id:1` на `node_id:10`:

1. Выключите автоматическое управление статической группой.
2. Получите текущую конфигурацию статической группы.
3. Внесите изменения и примените измененную конфигурацию в качестве целевой конфигурации статической группы.

    В конфигурационном файле `config.yaml` измените значение `node_id`, заменив идентификатор удаляемого хоста на идентификатор добавляемого:

    ```yaml
    ...
    groups:
      ...
      rings:
        ...
        fail_domains:
        - vdisk_locations:
          - node_id: 10
            path: /dev/vda
            pdisk_category: SSD
        ...
    ...
    ```

    Измените путь `path` и категорию `pdisk_category` диска, если на хосте с `node_id: 10` они отличаются.
4. Перейдите на страницу мониторинга {{ ydb-ui-name }} и убедитесь, что VDisk статической группы появился на целевом физическом диске и реплицируется. Подробнее см. [{#T}](../../../reference/ydb-ui/ydb-monitoring.md#static-group).
5. Уберите целевую конфигурацию статической группы из файла конфигурации и включите автоматическое управление конфигурацией статической группы.
