## Кирилл Курдюков — YDB и C#: история большой любви

{% include notitle [practice_tag](../_includes/tags.md#practice) %}

Доклад Кирилла Курдюкова на конференции DotNext посвящён интеграции .NET-платформы с {{ ydb-short-name }}. В нём рассматривается задача разработки клиента для Distributed SQL СУБД в экосистеме, где официальные SDK уже существовали для Java, Go, Python и C++, но поддержка .NET отсутствовала. Разбираются ключевые аспекты и проблемы, которые необходимо учесть для успешной интеграции. В докладе показано, что интеграция {{ ydb-short-name }} с .NET — это союз по любви, а не брак по расчёту.

Доклад будет интересен [разработчикам приложений](../../dev/index.md) на .NET и C#, а также инженерам, которые выбирают или внедряют клиентские SDK для работы с распределёнными СУБД.
