В этом докладе представим себя в роли разработчиков, перед которыми стоит задача интеграции .NET-платформы с новой СУБД. Какие ключевые аспекты и проблемы необходимо учесть для успешной интеграции? Увидим, что интеграция YDB с .NET — это союз по любви, а не брак по расчету.

Доклад будет интересен [разработчикам приложений](../../dev/index.md) на .NET и C#, а также инженерам, которые выбирают или внедряют клиентские SDK для работы с распределёнными СУБД.
