# Аутентификация

{{ ydb-short-name }} поддерживает несколько способов аутентификации при подключении к серверу. Выбор способа зависит от того, где работает клиентское приложение (в доверенной зоне {{ ydb-short-name }} или вне её) и где развёрнута серверная часть {{ ydb-short-name }} (в Docker-контейнере, {{ yandex-cloud }}, data cloud или на отдельном кластере).

В этом разделе приведены примеры настройки аутентификации в разных {{ ydb-short-name }} SDK. Общее описание принципов аутентификации в SDK можно прочитать в статье [Аутентификация в SDK](../../reference/ydb-sdk/auth.md).

- [Сервис метаданных](auth-metadata.md)
