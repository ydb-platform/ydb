- Иначе, если задана непустая переменная `YDB_OIDC_ISSUER`, используется [аутентификация OIDC](../../oidc.md). Остальные настройки задаются через `YDB_OIDC_FLOW`, `YDB_OIDC_CLIENT_ID`, `YDB_OIDC_CLIENT_SECRET`, `YDB_OIDC_ACCESS_TOKEN`, `YDB_OIDC_SCOPE` и `YDB_OIDC_CACHE_PATH`. Переменные для секрета и токена содержат сами значения, а не пути к файлам. Подробности см. в [таблице параметров](../../oidc.md#options).
