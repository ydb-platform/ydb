- `--oidc-config <filepath>`: включает OIDC/OAuth-аутентификацию с помощью YAML-файла `<filepath>`. Файл должен содержать HTTPS-параметр `issuer` и ровно один сценарий: `static_credentials`, `client_credentials_grant` или `device_authorization_grant`. Client Credentials использует `client_id` и `client_secret`; Device Authorization использует `client_id` и выводит URL проверки и пользовательский код. Для статических учётных данных можно указать `client_id` и `refresh_token`, чтобы включить обновление токена. Scope `openid` запрашивается всегда. Опциональный `cache_path` сохраняет ротированные токены в приватном JSON-файле, доступном только владельцу; относительный путь вычисляется от каталога OIDC-конфигурации.
