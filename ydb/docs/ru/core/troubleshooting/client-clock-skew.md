# Расхождение времени между клиентскими хостами и кластером

Сдвиг системных часов на хосте клиентского приложения может приводить к ошибкам аутентификации — особенно при выдаче токена через IAM.

Проверка Healthcheck [`NODES_TIME_DIFFERENCE`](../reference/ydb-sdk/health-check-api.md) сравнивает системное время узлов кластера между собой. Время на хостах клиентских приложений она не проверяет. Поэтому если Healthcheck не показывает проблем, а ошибки аутентификации возникают только у части клиентов, проверьте время на хостах этих клиентов.

## Симптомы {#symptoms}

* Ошибки при аутентификации по [ключу сервисного аккаунта](../security/authentication.md#iam). В этом режиме приложение формирует JWT для запроса токена и указывает в нём текущее время по системным часам хоста. Если часы спешат или отстают, сервис IAM отклоняет этот JWT.
* Если SDK определяет момент обновления токена по локальным часам, при их отставании клиент может отправить в кластер уже истёкший токен.
* Ошибки возникают только на отдельных хостах, например на новых машинах или в окружениях без настроенной синхронизации времени.

{% note info %}

Ошибки `DeadlineExceeded` при нормальных задержках кластера обычно не связаны с расхождением времени: транспортный таймаут — это длительность ожидания на стороне клиента. В этом случае проверьте значения таймаутов (см. [{#T}](../dev/timeouts.md)).

{% endnote %}

## Диагностика {#diagnostics}

Чтобы проверить синхронизацию времени на клиентском хосте, выполните:

```bash
chronyc tracking
chronyc sources -v
```

В выводе `chronyc tracking` смотрите поля `System time` (текущее смещение) и `Leap status` (должно быть `Normal`). Если chrony не установлен, проверьте в выводе `timedatectl`, что системные часы синхронизированы.

## Рекомендации {#recommendations}

Настройте на клиентских хостах синхронизацию времени с помощью `chrony` или `ntpd` и нескольких NTP-источников из вашей среды. Примеры конфигурации см. в статье [{#T}](performance/system/system-clock-drift.md#ntp-examples).

Основное решение — синхронизировать часы.
