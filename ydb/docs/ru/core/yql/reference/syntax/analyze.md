# ANALYZE

`ANALYZE` собирает статистику для [стоимостного оптимизатора {{ ydb-short-name }}](../../../concepts/query_execution/optimizer.md).

## Синтаксис

```yql
ANALYZE <path_to_table> [ (<column_name> [, ...]) ] [SAMPLE <rate>]
```

Оператор выполняется синхронно и завершается, когда запрошенная статистика собрана и актуальна. Один оператор `ANALYZE` обрабатывает только одну таблицу.

* `path_to_table` — путь к таблице, для которой собирается статистика.
* `column_name` — столбцы, статистику которых нужно собрать. Если список не задан, `ANALYZE` обрабатывает все столбцы таблицы. [Многоколоночная статистика](create_table/statistics.md) обновляется, только если в список входят все её столбцы. Сводная статистика таблицы обновляется независимо от того, указан ли список столбцов.
* `SAMPLE <rate>` — сбор статистики по выборке. `<rate>` — числовое выражение, которое должно возвращать конечное значение типа `Double` из интервала `(0, 1]`. `SAMPLE 1` читает всю таблицу, как и `ANALYZE` без `SAMPLE`.

Список собираемой статистики приведён в [{#T}](../../../concepts/query_execution/optimizer.md#statistics). Многоколоночную статистику объявляют с помощью [STATISTICS](create_table/statistics.md) в `CREATE TABLE` или [ALTER TABLE](alter_table/statistics.md).

## Что собирается

По каждому запрошенному столбцу `ANALYZE` сохраняет:

* число значений и число различных значений;
* минимум и максимум, если тип столбца числовой;
* [count-min sketch](https://en.wikipedia.org/wiki/Count%E2%80%93min_sketch), если различных значений меньше 80%;
* гистограмму равной ширины, если столбец числовой и в нём больше одного значения.

Каждый `ANALYZE` собирает сводную статистику таблицы и статистику отдельных столбцов из списка выше. Чтобы собрать статистику сразу по нескольким столбцам, объявите кортеж в [STATISTICS](create_table/statistics.md) и укажите в `ANALYZE` все столбцы этого кортежа.

## Выборка

При доле меньше `1` статистика приблизительная.

* Строковая таблица читается за один проход. Каждая строка включается в выборку с вероятностью `<rate>` (выборка Бернулли).
* Для колоночной таблицы шарды выбираются случайно. Читается хотя бы один шард, иногда все.

Статистика по выборке хранится отдельно от последней полной статистики. Для фонового сбора отсчёт ведётся от последнего полного `ANALYZE`. Следующий полный `ANALYZE` — без `SAMPLE` или с `SAMPLE 1` — заменяет статистику по выборке. Подробнее см. в разделе [«Фоновый сбор»](../../../concepts/query_execution/optimizer.md#statistics).

## Фоновая операция

SQL операция `ANALYZE` выполняется синхронно и ожидает завершения. При этом создаётся фоновая операция для наблюдаемости. Используйте команду [operation list](../../../reference/ydb-cli/operation-list.md) для отслеживания прогресса фоновых операций `ANALYZE`.
