# CHECKSUM TABLE

`CHECKSUM TABLE` вычисляет контрольную сумму — короткую строку, которая представляет данные таблицы. С её помощью можно проверить, совпадает ли содержимое скопированной или восстановленной таблицы с оригиналом.

Чтобы вычислить контрольную сумму таблицы `my_table`, выполните:

```yql
CHECKSUM TABLE my_table;
```

Команда читает все строки и возвращает контрольную сумму и количество строк. В расчёт входят все пользовательские столбцы, включая столбцы первичного ключа. Системные столбцы не учитываются.

## Синтаксис

Оператор имеет следующий синтаксис. Квадратные скобки обозначают необязательную часть:

```yql
CHECKSUM TABLE <table_path> [WITH (ALGORITHM = "<algorithm>")];
```

Где:

- `table_path` — имя или путь к таблице. Пути обрабатываются по тем же правилам, что и в [`SELECT`](select/index.md), включая [`PRAGMA TablePathPrefix`](pragma.md#table-path-prefix).
- `algorithm` — алгоритм вычисления контрольной суммы. Указывайте его название непосредственно в кавычках, соблюдая регистр букв. Если `WITH` не указан, используется `CityHash64`.

| Алгоритм | Длина контрольной суммы |
| --- | --- |
| `CityHash64` | 16 символов |
| `CityHash128` | 32 символа |
| `Sha256` | 64 символа |

Например, чтобы использовать `Sha256` с абсолютным путём к таблице, заключите путь в обратные кавычки:

```yql
CHECKSUM TABLE `/Root/my_database/my_table` WITH (ALGORITHM = "Sha256");
```

## Результат {#result}

Оператор возвращает ровно одну строку со следующими столбцами:

| Столбец | Тип | Описание |
| --- | --- | --- |
| `algorithm` | `Utf8` | Алгоритм, использованный для вычисления контрольной суммы. |
| `count` | `Uint64` | Количество строк в таблице. |
| `hash` | `String` | Контрольная сумма в виде шестнадцатеричной строки, в формате результата [`String::HexEncode`](../udf/list/string.md). |
| `version` | `Uint32` | Версия формата контрольной суммы, сейчас — `1`. |

Для пустой таблицы `count` равен `0`, а контрольная сумма состоит только из символов `0`. Её длина по-прежнему зависит от алгоритма. При алгоритме по умолчанию результат выглядит так:

| algorithm | count | hash | version |
| --- | --- | --- | --- |
| `CityHash64` | `0` | `0000000000000000` | `1` |

## Перед выполнением

- Нужны те же права на чтение таблицы, что и для `SELECT`.
- Команда читает всю таблицу, поэтому проверка большой таблицы может занять время и создать дополнительную нагрузку на базу данных.

Чтобы проверить выбранные строки или столбцы либо получить отдельную контрольную сумму для каждой группы, используйте [примеры `DigestAggregate`](../udf/list/digest-aggregate.md#examples).
