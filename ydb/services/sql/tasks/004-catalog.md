## Сделать

Фиксированные ответы, которых хватает, чтобы `psql` дошёл до приглашения: `SELECT version()` и те запросы `pg_catalog` / `pg_type`, которые libpq шлёт при старте. Список снять с реального `psql` к PostgreSQL 18 и зафиксировать в тесте. Лишний каталоговый запрос — `0A000`. Это заглушка, не живой каталог.

## Тест

Тест прогоняет сохранённый список стартовых запросов и проверяет ответы. Запрос вне списка — `0A000`.

## Готово, когда

Клиент, который шлёт только этот список, доходит до готовности сессии.

## Не трогать

- `ydb/core/tx/datashard`, `ydb/core/tx/columnshard` и их протобуфы
- `yql/` и `ydb/core/kqp`: ни `PEERDIR`, ни вызовы
- remote `official`
- код datashard и columnshard в одном читателе

Пока этой возможности нет в коде, она отвечает SQLSTATE `0A000`, текст `not supported`, сессия жива.
## Перед коммитом

```bash
./ya make --build relwithdebinfo -tA ydb/services/sql
```

Коммит только после зелёного прогона. В прогон входят тесты `pg8000`, когда они уже есть.
