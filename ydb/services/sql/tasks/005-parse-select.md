## Сделать

Свой лексер и парсер подмножества PostgreSQL. Не генерировать из `gram.y` и не брать грамматики `yql/essentials`. Если парсер генерируется — ANTLR 4.13.2, рантайм `contrib/libs/antlr4_cpp_runtime`.
Первый кусок: `SELECT` списка столбцов или `*` и `FROM` одной таблицы. Идентификаторы без кавычек складываются в нижний регистр, в двойных кавычках сохраняются. Незнакомый узел — `0A000` с текстом узла.

## Тест

Юнит без кластера: дерево для `SELECT a, b FROM t` и для кавычек. Незнакомая команда — `0A000`.

## Готово, когда

Парсер отдаёт дерево только для этого среза.

## Не трогать

- `ydb/core/tx/datashard`, `ydb/core/tx/columnshard` и их протобуфы
- `yql/` и `ydb/core/kqp`: ни `PEERDIR`, ни вызовы
- remote `official`
- код datashard и columnshard в одном читателе

Пока этой возможности нет в коде, она отвечает SQLSTATE `0A000`, текст `not supported`, сессия жива.
## Перед коммитом

```bash
./ya make --build relwithdebinfo -tA ydb/services/sql
```

Коммит только после зелёного прогона. В прогон входят тесты `pg8000`, когда они уже есть.
