## Сделать

`WHERE` из сравнений и `AND`. Предикат по префиксу ключа сужает диапазон. Остаток предиката считается в сервисе: datashard поле `Program` отвергает. `OR` в ключ не пушится. `LIMIT` после слияния ответов. Параллельный `TEvRead` на каждый шард диапазона, ключи одного шарда — один вызов. Сравнение без границы ключа — `0A000`, пока полный скан выключен. Продолжение — `TEvReadAck`, каждый ответ считается вызовом.

## Тест

Тест: таблица на двух datashard, `WHERE` по префиксу и `LIMIT` возвращает строки с обоих, не больше предела. Таблицу на два шарда готовит тест средствами YDB вне этого SQL, если `CREATE TABLE` не задаёт границы.

## Готово, когда

Ответ содержит строки обоих шардов и не длиннее LIMIT.

## Не трогать

- `ydb/core/tx/datashard`, `ydb/core/tx/columnshard` и их протобуфы
- `yql/` и `ydb/core/kqp`: ни `PEERDIR`, ни вызовы
- remote `official`
- код datashard и columnshard в одном читателе

Пока этой возможности нет в коде, она отвечает SQLSTATE `0A000`, текст `not supported`, сессия жива.
