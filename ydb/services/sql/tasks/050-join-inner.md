## Сделать

Два входа — две фазы, сначала один снимок на обе таблицы. Nested loop и hash join. Исполнение в сервисе. `ON` — равенство столбцов. Nested loop группирует ключи внутреннего входа по шарду в один `TEvRead`. Hash join читает каждый вход один раз. План с лишними вызовами проигрывает. Неравенство в `ON` — `0A000`. Другие виды соединения в этом коммите — `0A000`.

## Тест

Тест: внутреннее соединение двух таблиц возвращает только совпавшие строки. Число вызовов внутреннего входа не равно числу внешних строк.

## Готово, когда

Результат совпадает с парами равных ключей.

## Не трогать

- `ydb/core/tx/datashard`, `ydb/core/tx/columnshard` и их протобуфы
- `yql/` и `ydb/core/kqp`: ни `PEERDIR`, ни вызовы
- remote `official`
- код datashard и columnshard в одном читателе

Пока этой возможности нет в коде, она отвечает SQLSTATE `0A000`, текст `not supported`, сессия жива.
