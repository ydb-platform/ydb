## Сделать

`AND` уже есть. Добавить `OR`, `NOT` и скобки. Сравнение с `NULL` неизвестно, неизвестное в `WHERE` строку не пропускает. `OR` не сливается в один ключ: каждая ветка читается отдельно, если у неё есть своё ограничение ключа, строки объединяются по первичному ключу. Ветка без ограничения ключа — `0A000`, шард не читается. `NOT` фильтрует уже прочитанные строки и требует, чтобы остальной ключ был ограничен. `NOT` без такого ключа — `0A000`.

## Тест

Тест через сессию, без сокета: `WHERE id = 1 OR id = 2` возвращает обе строки. `WHERE id = 1 AND NOT note = 'x'` не возвращает строку с `note = 'x'`. `WHERE NOT id = 1` — `0A000`.

## Готово, когда

`AND`, `OR` и `NOT` дают те же строки, что PostgreSQL, а чтение без ключа не включается.
