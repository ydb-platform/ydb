## Changes in top level statements

Introduced a new [`MATERIALIZE`](../syntax/materialize.md) statement

Introduced a new [`COMBINE`](../syntax/combine.md) statement.

## Changes in built-in functions

Added `Decimal` support to [`ListFromRange`](../builtins/list.md#listfromrange).
Added functions [`AsErased`, `PeekErased`](../builtins/basic.md#type_erasure) to support value type erasure.

## Changes in expressions

[Arithmetic operators](../syntax/expressions.md#math-operators) now support operands with different `Decimal(N, M)` types. Both operands are implicitly converted to a common Decimal type.
