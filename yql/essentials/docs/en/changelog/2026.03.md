## Math module {#math-module}
Added `Math::Expm1` and `Math::Log1p` for accurate computation near zero.

## String module {#string-module}
Added `String::Soundex` for generating four-character Soundex codes.

## Digest module {#digest-module}
Added `Digest::Crc32` for the standard IEEE CRC-32 checksum.
Added `Digest::Sha224` and `Digest::Sha384` for the SHA-224 and SHA-384 hash algorithms.

## DateTime module {#datetime-module}
Added `DateTime::Init` for creating a date-time resource from its components.
