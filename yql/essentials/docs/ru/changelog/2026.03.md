## Модуль Math {#math-module}
Добавлены `Math::Expm1` и `Math::Log1p` для точных вычислений вблизи нуля.

## Модуль String {#string-module}
Добавлена функция `String::Soundex` для формирования четырёхсимвольных кодов Soundex.

## Модуль Digest {#digest-module}
Добавлена функция `Digest::Crc32` для стандартной контрольной суммы IEEE CRC-32.
Добавлены `Digest::Sha224` и `Digest::Sha384` для алгоритмов хеширования SHA-224 и SHA-384.

## Модуль DateTime {#datetime-module}
Добавлена функция `DateTime::Init` для создания ресурса даты и времени из компонентов.
