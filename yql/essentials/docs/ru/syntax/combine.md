# COMBINE

Группирует строки двух входных таблиц по общему ключу и применяет UDF или [лямбда-функцию](expressions.md#lambda) к каждой группе. В отличие от [JOIN](join.md), `COMBINE` не строит декартово произведение совпавших строк. Вместо этого функция получает все строки с одинаковым ключом в виде двух списков и может реализовать произвольную логику сопоставления.

## Синтаксис

```yql
COMBINE input1 AS alias1 [PRESORT presort_expression1 [ASC | DESC], ...]
WITH input2 AS alias2 [PRESORT presort_expression2 [ASC | DESC], ...]
ON alias1.key_expression = alias2.key_expression [AND ...]
USING function(item_expression1, item_expression2)
```

## Доступность

`COMBINE` доступен начиная с версии языка [2026.02](../changelog/2026.02.md).

## Описание

В секции `ON` указывается одно или несколько условий равенства, объединённых с помощью `AND`. Если предикатов несколько, результатом будет составной ключ со значениями компонент в виде кортежа, иначе ключ скалярный.

Для каждого ключа, присутствующего хотя бы в одном из входов, `COMBINE` вызывает функцию с тремя аргументами:

1. Общий ключ, заданный в секции `ON`.
2. Список значений, полученных вычислением выражения из первого аргумента `USING` для строк первого входа с этим ключом.
3. Список значений, полученных вычислением выражения из второго аргумента `USING` для строк второго входа с этим ключом.

Если ключ встречается только в одном входе, список для другого входа будет пустым. Таким образом, на уровне групп `COMBINE` имеет семантику `FULL JOIN`.

Два выражения в `USING` определяют, какое значение будет добавлено в список для каждой строки соответствующего входа. Чтобы передать строку целиком в виде структуры, используйте `TableRow()`. Другие выражения позволяют выбрать только необходимые столбцы или вычислить значение перед добавлением в список.

Опциональная секция `PRESORT` задаёт порядок строк внутри каждой группы до передачи их значений в функцию. Для каждого входа указывается своя секция `PRESORT`. В выражениях сортировки поддерживаются ключевые слова `ASC` (по умолчанию, по возрастанию) и `DESC` (по убыванию). Без `PRESORT` порядок элементов в списках не определён.

Функция в `USING` может возвращать те же выходные типы, что и в [PROCESS](process.md): структуру, опциональную структуру, список или поток структур. Результат преобразуется в плоскую таблицу. Опциональное значение позволяет не возвращать результат для группы, а список или поток -- вернуть несколько строк результата.

{% note info "Примечание" %}

`COMBINE` удобно использовать, когда строки с одинаковым ключом нужно обработать вместе, но размножение строк при обычном соединении нежелательно, например при сопоставлении временных интервалов или реализации специализированной логики слияния.

{% endnote %}

## Примеры

```yql
$count_rows = ($key, $left_rows, $right_rows) -> {
    RETURN <|
        key: $key,
        left_count: ListLength($left_rows),
        right_count: ListLength($right_rows)
    |>;
};

COMBINE my_table1 AS L
WITH my_table2 AS R
ON L.key = R.key
USING $count_rows(TableRow(), TableRow());
```

```yql
$zip_rows = ($key, $left_rows, $right_rows) -> {
    RETURN <|
        key: $key.0,
        subkey: $key.1,
        rows: ListZipAll($left_rows, $right_rows)
    |>;
};

COMBINE my_table1 AS L
    PRESORT L.timestamp
WITH my_table2 AS R
    PRESORT R.timestamp
ON L.key = R.key AND L.subkey = R.subkey
USING $zip_rows(TableRow(), TableRow());
```
