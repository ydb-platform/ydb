# Отладочные и служебные {#debug}

## `config.flags("ValidateUdf", "Lazy")`

| Тип значения | По умолчанию | Допускается в проектных настройках |
| --- | --- | --- |
| Строка: None / Lazy / Greedy | None | Да |

Валидация результатов UDF на соответствие объявленной сигнатуре. Greedy режим форсирует материализацию «ленивых» контейнеров, а Lazy — нет.

## `config.flags("Diagnostics")`

| Тип значения | По умолчанию | Допускается в проектных настройках |
| --- | --- | --- |
| Флаг | false | Нет |

Получение диагностической информации от YQL в виде дополнительного результата запроса.

## `DebugPositions`

| Допускается в проектных настройках |
| --- |
| Нет |

Отключение дедубликации вычисления выражений, которые могут приводить к ошибкам (`Ensure`/`Unwrap` или вызов UDF).
Это может привести к замедлению запроса ценой увеличения точности позиции, которая будет привязана к runtime ошибке.

## `UdfBridge`

| Допускается в проектных настройках |
| --- |
| Нет |

Включает выполнение UDF в отдельном процессе.
Это может привести к замедлению запроса, но позволяет локализовать креши/нарушения протокола вызова UDF с точностью до одной библиотеки, либо свести их к проблеме внутри хост-процесса.

## `config.flags("LLVM")`

| Аргументы | Допускается в проектных настройках |
| --- | --- |
| Опциональная строка настроек LLVM | Да |

Задает настройки LLVM-компиляции вычислений. Значение `"OFF"` отключает LLVM; без второго аргумента передается пустая строка настроек.

## `config.flags("LLVM_OFF")`

| Аргументы | Допускается в проектных настройках |
| --- | --- |
| Без дополнительных аргументов | Да |

Отключает LLVM-компиляцию. Эквивалентно `PRAGMA config.flags("LLVM", "OFF");`.

## `config.flags("UdfSupportsYield")`

| Аргументы | Допускается в проектных настройках |
| --- | --- |
| Опционально `"true"` или `"false"` | Да |

Указывает, что scripting UDF поддерживают обработку сигнала `yield` в потоковых аргументах. Отсутствие второго аргумента равносильно значению `"true"`.
